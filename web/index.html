    What this build supports

    • Playback of one HLS or MP4 source per element, through hls.js and Media Source Extensions.
    • Picture from one source and sound from another, at independent volumes.
    • No cross-source timing: the web client does not align two live sources, and it does not buffer or replay history.
    • Seek only inside what the browser has buffered; live HLS starts at the live edge.
    • Browsers refuse to start sound without a click, so every source starts muted.
