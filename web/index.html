Sources

Picture and sound are chosen separately; every choice is written to the Go session through POST /api/scene.

    Scene

    picture none
    sound none
    What this build supports
    • One HLS or MP4 source per media element, through hls.js and Media Source Extensions.
    • Picture from one source and sound from another, at independent volumes.
    • No cross-source timing: two live sources are not aligned here, and nothing is buffered or replayed.
    • Peek only floats a second picture for comparing by eye; it changes nothing in the session.
    • Seeking stays inside what the browser has buffered; live HLS starts at the live edge.
    • Browsers refuse sound before a click, so every source starts muted.
